## What Is Cedar Grove Prep?

Cedar Grove Prep provides a focused browser workspace for interview preparation. Its lightweight, HTML-first design gives you a simple way to review material, rehearse answers, and keep preparation notes together without requiring a large application runtime.

The app runs in a web browser and works well with static hosting, making it suitable for quick local use as well as straightforward web deployment. Candidates, mentors, and teams can use it as a dedicated place to organize and revisit interview preparation.
